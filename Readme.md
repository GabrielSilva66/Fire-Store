# Fire System 🔥

**Fire System** is a web system designed to manage sales and inventory, providing full control over products.

## 📌 Project Overview

**Fire System** was created to streamline sales and inventory management, allowing businesses to organize their products, track transactions, and manage users securely. The system has a modern and intuitive interface built with **Thymeleaf and Bootstrap**, ensuring an excellent user experience.


## 🛠 Technologies Used

**Fire System** was developed using the following technologies:

- **Java 21** – The main programming language of the project.
- **Spring Boot 3.3.5** – A framework for rapid and efficient development.
- **Spring Data JPA** – For interacting with the relational database.
- **PostgreSQL** – Database used for data storage.
- **Flyway** – Database versioning and migration control.
- **Thymeleaf** – Template engine for dynamic HTML page rendering.
- **Bootstrap 5** – Framework for styling and responsive design.
- **Lombok** – To reduce boilerplate code in the project.

## 💻 How to Run the Project

### ✅ Prerequisites

- Java 21 installed
- Maven configured
- PostgreSQL database set up
